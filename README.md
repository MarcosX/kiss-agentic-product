# kiss-agentic-product

Product management skills following the Double Diamond framework. Covers Discover and Define; Develop and Deliver remain in kiss-agentic-development.

## Split
- Discover + Define: kiss-agentic-product (this repo)
- Develop + Deliver: kiss-agentic-development

## Skill flow
- brainstorming: explore ideas and frame problems
- discovering-opportunities: find user needs/opportunities (JTBD-focused)
- conducting-user-interviews: plan/conduct discovery interviews, synthesize themes
- prioritizing-opportunities: prioritize with explicit criteria and rationale
- prototyping-concepts: validate assumptions with cheapest way to learn

## Handoff convention
Product work produces a PRD (or equivalent) with: problem statement, success criteria/metrics, prioritized scope (in/out), assumptions & risks, evidence. Hand off to kiss-agentic-development's `writing-plans` - no dedicated handoff skill.
