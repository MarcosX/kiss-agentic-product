# Product glossary

- Double Diamond: Discover, Define, Develop, Deliver. This framework covers Discover + Define; Develop + Deliver live in kiss-agentic-development.
- Discover: Problem space exploration - understand users, needs, jobs to be done, opportunities.
- Define: Synthesize insights into clear problem statement, scope, and handoff artifacts.
- Opportunity: A user need/pain point worth addressing (separate from solutions).
- Job to be done (JTBD): The progress a user is trying to make in a given context.
- Evidence: Concrete observations/quotes/data that support insights/themes.
- Theme: Pattern across multiple pieces of evidence.
- Handoff: Convention-based transfer of PRD to kiss-agentic-development's writing-plans (no dedicated skill).
- Hooks vs rules: Hooks are cognitive reframes with observable completion bars; rules are enforced directives. Prefer hooks for open-field skills.
- Open-field vs narrow-bridge: Open-field allows judgment; narrow-bridge has contracts downstream depend on.
- Provider-agnostic: Skills must work with any coding agent without provider-specific references.
