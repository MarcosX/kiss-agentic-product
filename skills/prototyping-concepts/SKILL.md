## Workflow
1. **Identify assumptions** — list testable assumptions/hypotheses.
2. **Choose cheapest test** — pick smallest prototype to learn fastest.
3. **Build/prototype** — low-fi first (sketch/wireframe/mock) or working code only if needed as reference.
4. **Test** — validate against assumptions with users/stakeholders.
5. **Learn and iterate** — capture results, adjust or drop.
6. **Output** — learnings and decision ready for handoff.

Focus on learning, not polish. Progress to higher fidelity only when necessary.
